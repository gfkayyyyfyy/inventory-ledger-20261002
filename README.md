# 小型仓储库存台账

建设面向小型仓库的本地库存管理产品，逐步覆盖商品与 SKU、库位、入库出库、库存调整、盘点差异、操作流水、低库存清单和 CSV 交换。

计划采用：Python 3 标准库 / sqlite3 / csv / argparse。

当前已实现：单仓库、整数数量的本地库存台账，无需第三方包或联网。库位、盘点、调整、低库存及 CSV 交换暂不在范围内。

## 使用方式

通过 `python -m inventory --db 文件路径` 访问台账。数据库父目录需事先存在；指定文件不存在时自动建立台账，后续命令使用同一路径读写，数据持久保存。

```bash
# 登记商品（初始数量为零）
python -m inventory --db ./ledger.db add --sku DEMO-1 --name 演示螺母

# 入库 / 出库
python -m inventory --db ./ledger.db receive --sku DEMO-1 --qty 10
python -m inventory --db ./ledger.db issue   --sku DEMO-1 --qty 3

# 查询商品名称、当前数量与完整流水
python -m inventory --db ./ledger.db show --sku DEMO-1

# 只查看编号严格大于 2 的后续流水（可与 --type 同用，两个条件同时满足）
python -m inventory --db ./ledger.db show --sku DEMO-1 --after-id 2
python -m inventory --db ./ledger.db show --sku DEMO-1 --after-id 2 --type receive
```

`--after-id` 接受 0 至 9223372036854775807 的十进制非负整数（允许前导零），0 表示从最早流水开始；下界不要求实际存在，也不要求属于当前 SKU。筛选不改变商品当前数量，返回的流水保留原始编号、数量与余额，不重新编号或重算余额。

### 输出约定

- 成功：退出码 0，标准输出为单个 JSON 对象。
  - `add`/`receive`/`issue`：`{"sku", "name", "quantity"}`
  - `show`：额外包含 `movements` 数组，按流水编号升序；流水对象为 `{"id", "type", "quantity", "balance"}`，无流水时为 `[]`。
  - `show` 可用 `--type`（`receive`/`issue`）按类型筛选，用 `--after-id ID` 只返回编号严格大于 ID 的流水；二者可同时使用，返回同时满足两项条件的流水。无匹配时退出码仍为 0、`movements` 为 `[]`，商品当前数量照常返回。
  - 所有 `quantity` 与流水的 `quantity`、`balance` 均为精确 JSON 整数（不会出现小数、科学计数法近似值或字符串）。
- 参数或业务错误（空 SKU/名称、重复登记、商品不存在、无效数量、出库超过余额、入库后余额超过库存上限、非法 `--after-id`/`--type`）：退出码 2，原因写入标准错误，标准输出为空，数据不改变。
  - `--qty` 只接受 1 至 9223372036854775807 的十进制正整数（允许前导零，前导零不改变数量含义）；缺值、零、负数、小数、非数字或超过单次数量上限时按参数错误拒绝，错误信息包含参数名 `--qty`、允许的上限与收到的值。
  - 即使本次数量本身合法，入库后余额超过库存上限 9223372036854775807 时也按业务错误拒绝，错误信息说明库存上限、当前余额与本次数量。
  - `--after-id` 缺值、空字符串、负数、小数、非数字或超出 0–9223372036854775807 范围时按参数错误拒绝，错误信息包含参数名与原因。
- 数据库无法打开或读写：退出码 1，原因写入标准错误。

### 业务规则

- SKU 与名称去掉两端空白后不能为空；所有命令按去空白后的 SKU 精确查找，SKU 区分大小写。
- 数量只接受 1 至 9223372036854775807（2^63-1）的十进制正整数（拒绝零、负数、小数、非数字；允许前导零）。数量与余额均为精确整数：受 SQLite INTEGER 64 位有符号整数精度限制，库存余额限定在 0 至 9223372036854775807，边界值合法；若本次入库会使余额超过上限，即使数量自身合法也拒绝执行，余额与流水均不改变。
- 每次入库/出库都成功时只新增一条流水，记录唯一递增编号、类型（`receive`/`issue`）、本次正整数数量和操作后余额；余额更新与流水写入在同一事务内同时生效或同时不生效。登记和查询不产生流水。
- 出库数量等于余额时允许成功，余额变为零。
- `show --after-id ID` 按流水编号查看后续记录：仅返回该 SKU 中 `id > ID` 的流水，编号升序排列，与 `--type` 同用时取交集；筛选只影响返回的行，商品的 `sku`、`name`、`quantity` 以及各流水的原始编号、数量、余额均不变。
- 不同数据库文件的数据各自独立。

## 运行测试

出入库数量边界（含 64 位整数上限与库存上限）的回归测试位于 `tests/`，仅使用 Python 标准库，每个用例使用独立临时数据库，可重复执行。

```bash
python -m unittest discover
```

全部通过时输出 `OK`（如环境只有 `python3`，相应替换命令名）。
